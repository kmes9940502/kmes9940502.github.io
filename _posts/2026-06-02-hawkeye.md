# 概要:
Hawkeye Keylogger是一個老牌鍵盤側錄器，使用C#編寫，早在2016年就有許多活動紀錄，這隻樣本已經到V9了，VirusTotal上記錄2023年又開始活躍，隨著釣魚郵件進行散播，功能大致上有盜取設備信息、鍵盤紀錄、螢幕截圖等等，甚至還可以偷拍你的webcam

# 分析
## Loader

Wireshark 獲得的執行檔案是用 **AutoIt 3** 編寫的 loader
![alt text](../assets/img/posts/2026-06-02-hawkeye/DIE_tkraw.png)

我們可以用 [unAutoIt](https://github.com/digitalsleuth/UnAutoIt) 還原成 AutoIt 腳本，內容如下:
![alt text](../assets/img/posts/2026-06-02-hawkeye/Autoit.png)
腳本除了加入變數/字串名稱混淆之外，也使用兩個 function 做字串混淆
![alt text](../assets/img/posts/2026-06-02-hawkeye/obf.png)
可以看到腳本中大量出現兩個function混淆所有的字串與bytes，我們可以按照這兩個function寫個腳本解這些混淆
腳本放在我的repo中了
loader將resource中的 **hvax641** 與 **pcalua2** 解密成 malware 本體
![alt text](../assets/img/posts/2026-06-02-hawkeye/dec_resource.png)
解密resource的function
![alt text](../assets/img/posts/2026-06-02-hawkeye/decrypt_resource_function.png)
shellcode 會 process hollowing `RegAsm.exe` 注入並執行 malware
![alt text](../assets/img/posts/2026-06-02-hawkeye/process_holowing.png)
在解混淆後獲得Shellcode:
![alt text](../assets/img/posts/2026-06-02-hawkeye/shellcode_sig.png)
硬編碼 shellcode 解出來後開頭是：

```text
55 8B EC 8B 4D 08 ...
```

其中 `55 8B EC` 是典型 32-bit x86 函式 prologue：

```asm
push ebp
mov  ebp, esp
```
注入shellcode，在DllCallAddress的參數中可以看到shellcode的起始位置為 0xBE
![alt text](../assets/img/posts/2026-06-02-hawkeye/shellcode_loading.png)
傳入三個參數
實際值：

```text
arg1 = 'C:\Windows\Microsoft.NET\Framework\v2.0.50727\RegAsm.exe'
arg2 = ''
arg3 = hvax641 + pcalua2 解密後的 .NET PE bytes
```
![alt text](../assets/img/posts/2026-06-02-hawkeye/loader_3args.png)

## Shellcode
首先 IDA 中還原 funcion `0xBE` 正好也是三個參數，說明這是 shellcode Entrypoint 沒錯
![alt text](../assets/img/posts/2026-06-02-hawkeye/IDA_shellcode_args.png)

從 malware 本體讀取 `IMAGE_DOS_HEADER` 的信息
![alt text](../assets/img/posts/2026-06-02-hawkeye/IDA_shellcode_load_dos_header.png)
然後進行 process hollowing，這邊呼叫了 `CreateProcessW` 啟動 `RegAsm.exe` 並且將 `dwCreationflags`設為 4 ，也就是 `CREATE_SUSPENDED`
![alt text](../assets/img/posts/2026-06-02-hawkeye/IDA_shellcode_createprocess_hollowing.png)

看到這邊基本可以確定其功能了，有興趣的朋友可以[下載樣本](https://github.com/kmes9940502/malware-detection-rules/blob/main/malware/HawkEye_SMTP.zip)更深入分析
